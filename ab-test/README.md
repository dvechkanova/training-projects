# A/B-тест интернет-магазина: оценка гипотез по увеличению выручки

## Описание проекта
Отдел маркетинга крупного интернет-магазина подготовил список гипотез
для увеличения выручки. Задача — приоритизировать гипотезы, запустить
A/B-тест и оценить его результаты по данным о заказах и посетителях
(август 2019).

## Используемый стек
- Python: pandas, numpy, scipy, matplotlib
- Статистика: тест Манна–Уитни, перцентильный анализ выбросов

## Данные
- `orders.csv` — заказы: transactionId, visitorId, date, revenue, group
- `visitors.csv` — визиты по дням и группам: date, group, visitors
- `hypothesis.csv` - оценки гипотез Hypothesis, Reach, Impact, Confidence, Efforts

## Ход анализа
1. Предобработка: проверка дубликатов (58 пользователей попали в обе группы — исключены).
2. Расчёт кумулятивных метрик: выручка, средний чек, конверсия по группам.
3. Выявление аномалий: перцентильный анализ (95-й и 99-й перцентили) по количеству заказов и выручке.
4. Проверка гипотез тестом Манна–Уитни на «сырых» и «очищенных» данных.

## Приоритизация гипотез
Гипотезы маркетинга приоритизированы двумя фреймворками:

- **ICE** (Impact × Confidence / Efforts): лидеры — акция в день рождения (16.2),
  новые каналы трафика (13.3), форма подписки (11.2).
- **RICE** (Reach × Impact × Confidence / Efforts): лидеры — форма подписки (112.0),
  блоки рекомендаций (56.0), новые каналы трафика (40.0).

Сдвиг рейтингов объясняется учётом охвата (Reach): гипотезы, затрагивающие
всех пользователей, поднялись в приоритете; узкие гипотезы (Reach = 1) опустились.


## Результаты
- Конверсия группы B статистически значимо выше: p = 0.011 по сырым данным, p = 0.013 по очищенным. Относительный прирост группы B — 16–18%.
  Эффект устойчив к фильтрации выбросов.
- Значимых различий по среднему чеку нет (p = 0.829): на сырых данных различие 28.7% получено случайно, после очистки −1.1% в пользу A.
- Обнаружены аномалии: заказы дороже 20 000 руб. (95-й перцентиль — 26 785 руб.) и пользователи с 3+ заказами. Всего исключено 77 аномальных пользователей.

Положительный эффект зафиксирован по конверсии и количеству заказов.
Рост среднего чека данными не подтверждён: выручка на пользователя вырастает пропорционально конверсии без изменения чека.
